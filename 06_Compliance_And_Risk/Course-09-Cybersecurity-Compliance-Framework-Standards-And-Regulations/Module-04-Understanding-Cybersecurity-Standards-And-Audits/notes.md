# Notes

## Cybersecurity Industry Standards

### OWASP
- OWASP provides guidance for improving application security.
- Focuses on common web application vulnerabilities and risks.
- Helps developers and security teams implement secure coding practices.
- OWASP resources support security awareness and risk reduction.

### NIST
- NIST publishes cybersecurity standards, guidelines, and best practices.
- Supports risk management and security program development.
- Widely adopted across government and private organizations.
- Provides structured approaches for identifying and managing risks.

### ISO
- ISO develops internationally recognized standards.
- ISO security standards help organizations establish information security management systems.
- Encourages continuous improvement and risk-based security practices.
- Supports regulatory and compliance objectives.

### IEEE
- IEEE develops technical standards for technology and engineering fields.
- Contributes to consistency, interoperability, and security across systems.
- Supports the development and adoption of secure technologies.

## Audits
- Audits assess whether security controls are properly implemented.
- Help identify compliance gaps and security weaknesses.
- Can be internal or external.
- Review policies, procedures, documentation, and technical controls.
- Findings support corrective actions and continuous improvement.

## Key Takeaways
- Cybersecurity standards provide structured security guidance.
- OWASP focuses on application security best practices.
- NIST, ISO, and IEEE contribute important security frameworks and standards.
- Audits verify compliance and control effectiveness.
- Standards and audits help organizations strengthen security and governance programs.
