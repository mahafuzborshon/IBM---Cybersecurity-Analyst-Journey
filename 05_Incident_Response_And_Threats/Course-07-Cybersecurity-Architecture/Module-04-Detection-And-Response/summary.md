# Detection and Response

In this module, I learned how cybersecurity teams detect threats, analyze attacks, and respond to security incidents. I explored how detection and response are important parts of cybersecurity architecture and how organizations reduce damage during cyberattacks.

I studied indicators of compromise (IOCs) and learned how threat intelligence helps security teams identify suspicious activity and emerging threats. The module also introduced vulnerability assessment approaches and how organizations evaluate security weaknesses before attackers can exploit them.

During the hands-on lab, I analyzed recent threat reports using X-Force Threat Exchange and gained experience reviewing real-world cyber threat information.

I also learned about incident response frameworks and the different stages involved in handling security incidents. The airport cyberattack case study helped me understand how detection and response processes work in real-world situations.

Overall, this module improved my understanding of threat detection, incident response, threat intelligence, and security operations within cybersecurity architecture.
