# Network, Application, and Data Security

In this module, I explored the major security domains that protect networks, applications, and sensitive data inside organizations. I learned how security architecture is designed to secure infrastructure, applications, and information from different types of threats.

I studied network security concepts and learned how organizations secure network infrastructure using layered security approaches. I also worked with secure network diagrams and reviewed a case study focused on IBM-powered network architecture.

The module also introduced application security and security architecture essentials. I learned about secure coding practices, application-layer risks, and the importance of designing secure applications from the beginning.

Another major topic was data security. I explored proactive security strategies, encryption concepts, and the importance of protecting sensitive data. I also learned about quantum-safe encryption and the role security architects play during incidents, audits, and reporting processes.

Overall, this module gave me a broader understanding of how different security domains work together to build strong cybersecurity architecture.
