# Notes

## Attack Phase

- Begins after the Planning and Discovery phases.
- Uses collected information to validate security weaknesses.
- Tests systems in an authorized and controlled manner.
- Demonstrates how vulnerabilities could impact an organization.
- Findings are documented for remediation.

## Penetration Testing Tools

- Help automate security assessments.
- Used for scanning, enumeration, and vulnerability identification.
- Support information gathering and attack simulation.
- Different tools are used depending on the testing objective.

## Port Scanning

- Discovers active hosts on a network.
- Identifies open, closed, and filtered ports.
- Detects running services and protocols.
- Helps identify potential attack surfaces.
- Commonly performed before exploitation.

## Nmap

- Popular network discovery and port scanning tool.
- Identifies open ports and running services.
- Supports host discovery and service detection.
- Can perform TCP and UDP scans.
- Widely used during penetration testing.

## Nmap GUI

- Graphical interface for Nmap.
- Simplifies scan configuration.
- Displays scan results in an organized format.
- Useful for beginners learning network scanning.

## Network Protocol Analyzers

- Capture and inspect network packets.
- Monitor network communication.
- Analyze protocols and traffic flow.
- Detect suspicious or malicious activities.
- Assist with troubleshooting and incident investigations.

## Key Takeaways

- The Attack phase validates discovered vulnerabilities.
- Penetration testing tools improve assessment efficiency.
- Port scanning identifies open ports and available services.
- Nmap is one of the most widely used network scanning tools.
- Network Protocol Analyzers help inspect packets and investigate network activity.
- Practical labs strengthened my understanding of real-world penetration testing techniques.
