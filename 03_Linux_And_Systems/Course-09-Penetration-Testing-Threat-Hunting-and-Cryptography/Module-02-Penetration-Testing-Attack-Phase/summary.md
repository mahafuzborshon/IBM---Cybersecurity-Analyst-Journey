# Module 02: Penetration Testing Attack Phase

In this module, I learned about the Attack phase of penetration testing, where the information collected during reconnaissance is used to identify and validate security vulnerabilities. I understood that this phase focuses on safely testing systems to determine whether identified weaknesses can actually be exploited.

I explored different penetration testing tools and learned how security professionals use specialized software to automate scanning, enumeration, and vulnerability assessment. I realized that choosing the right tool depends on the target environment and the objectives of the engagement.

Another important topic was port scanning. I learned how port scanning helps identify active hosts, open ports, and running services, allowing penetration testers to understand which services may be vulnerable to attacks.

During the hands-on labs, I practiced port scanning using penetration testing tools, Nmap, and the Nmap GUI. These activities helped me understand how different scanning techniques reveal valuable information about a target system without immediately exploiting it.

I also learned about Network Protocol Analyzers and how they capture and inspect network traffic for troubleshooting, monitoring, and security analysis. By examining packets, I understood how analysts can identify suspicious communication, diagnose network issues, and investigate security incidents.

Overall, this module gave me practical experience with some of the most widely used penetration testing tools while strengthening my understanding of port scanning, network analysis, and the Attack phase of a penetration testing engagement.
