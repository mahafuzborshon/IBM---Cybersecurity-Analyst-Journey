# Notes

## Penetration Testing

- Penetration testing is an authorized security assessment that simulates real-world attacks.
- It helps identify vulnerabilities before malicious attackers can exploit them.
- A penetration test follows a structured methodology and defined scope.
- Human analysis and reporting are essential parts of the process.

## Common Penetration Testing Myths

- Penetration testing is not the same as illegal hacking.
- Automated tools cannot replace manual testing.
- Vulnerability scanning and penetration testing serve different purposes.
- Authorization and Rules of Engagement (RoE) are required before testing begins.

## Planning Phase

- Define testing objectives.
- Determine the project scope.
- Identify target systems and assets.
- Obtain authorization.
- Establish Rules of Engagement (RoE).
- Set timelines and communication procedures.
- Ensure testing aligns with business requirements.

## Discovery Phase

- Collect information about the target environment.
- Identify systems, services, and network details.
- Perform reconnaissance before vulnerability testing.
- Build an understanding of the target's attack surface.

## Passive Reconnaissance

- Collects information without directly interacting with the target.
- Uses publicly available sources.
- Includes search engines, WHOIS records, social media, and company websites.
- Difficult for the target to detect.

## Active Reconnaissance

- Directly interacts with target systems.
- Includes port scanning, DNS queries, banner grabbing, and service enumeration.
- Provides more detailed technical information.
- More likely to be detected by security systems.

## Google Dorking

- Uses advanced Google search operators to locate publicly indexed information.
- Supports reconnaissance and OSINT activities.
- Common operators include:
  - `site:`
  - `filetype:`
  - `intitle:`
  - `inurl:`
  - `cache:`
- Should only be used ethically and with proper authorization.

## Key Takeaways

- Planning is the foundation of every penetration test.
- Discovery focuses on gathering information before exploitation.
- Passive and active reconnaissance provide different types of intelligence.
- Google Dorking is an effective OSINT technique during reconnaissance.
- Proper planning and information gathering improve the success of a penetration testing engagement.
