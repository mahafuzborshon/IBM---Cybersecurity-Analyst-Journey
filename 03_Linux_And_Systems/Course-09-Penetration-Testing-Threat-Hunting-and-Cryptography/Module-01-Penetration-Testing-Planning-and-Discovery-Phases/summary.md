# Module 01: Penetration Testing Planning and Discovery Phases

In this module, I learned about the first two stages of a penetration test: the Planning phase and the Discovery phase. I understood that every successful penetration test begins with proper planning, where the objectives, scope, authorization, and rules of engagement are clearly defined before any testing starts.

I learned what penetration testing is and why organizations use it to identify security weaknesses before attackers can exploit them. I also explored several common myths about penetration testing and realized that it is much more than running automated tools—it requires careful planning, manual analysis, and proper reporting.

During the Planning phase, I learned how penetration testers define the testing scope, identify target systems, communicate with stakeholders, and obtain authorization to ensure the assessment is conducted safely and ethically.

The Discovery phase introduced me to reconnaissance techniques. I learned the differences between passive reconnaissance, which collects publicly available information without interacting with the target, and active reconnaissance, which directly communicates with target systems to gather technical information.

I also completed a Google Dorking lab, where I practiced using advanced Google search operators to locate publicly available information. This activity showed me how Open-Source Intelligence (OSINT) can support reconnaissance while emphasizing the importance of using these techniques responsibly.

Overall, this module gave me a strong understanding of how proper planning and information gathering lay the foundation for an effective penetration testing engagement.
