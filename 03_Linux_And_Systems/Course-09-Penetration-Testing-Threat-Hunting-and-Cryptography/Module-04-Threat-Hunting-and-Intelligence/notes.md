# Notes

## Threat Hunting

- Proactively searches for hidden cyber threats.
- Identifies malicious activities that automated tools may miss.
- Uses hypotheses and investigations to detect attackers.
- Improves an organization's overall security posture.
- Complements traditional security monitoring.

## Threat Intelligence

- Collects and analyzes information about cyber threats.
- Helps organizations understand attacker tactics and techniques.
- Supports better security decisions and incident response.
- Converts raw data into actionable intelligence.

## Threat Intelligence Process

- Planning and Direction
- Data Collection
- Processing
- Analysis
- Dissemination
- Feedback and Continuous Improvement

## Threat Intelligence Sources

- Internal security logs
- Open-Source Intelligence (OSINT)
- Commercial threat intelligence feeds
- Government advisories
- Industry reports
- IBM X-Force Exchange
- Security communities and research organizations

## IBM X-Force Exchange

- Provides real-world threat intelligence.
- Shares Indicators of Compromise (IOCs).
- Includes malware, phishing, and vulnerability information.
- Helps organizations stay informed about emerging threats.

## Security Information and Event Management (SIEM)

- Collects logs from multiple systems.
- Correlates security events.
- Detects suspicious activities.
- Generates security alerts.
- Supports incident investigation and response.

## Artificial Intelligence (AI) in Threat Hunting

- Automates threat analysis.
- Detects anomalies and unusual behavior.
- Prioritizes high-risk alerts.
- Improves detection speed and accuracy.
- Assists security analysts with large datasets.

## User and Entity Behavior Analytics (UEBA)

- Monitors user and system behavior.
- Establishes normal activity baselines.
- Detects abnormal or suspicious behavior.
- Helps identify insider threats and compromised accounts.

## MITRE ATT&CK Framework

- Knowledge base of attacker tactics and techniques.
- Maps adversary behavior.
- Helps improve threat detection.
- Supports defensive security strategies.
- Widely used by SOC and threat hunting teams.

## Diamond Model of Intrusion Analysis

- Focuses on four core elements:
  - Adversary
  - Capability
  - Infrastructure
  - Victim
- Helps analyze cyber intrusion events.
- Supports threat intelligence investigations.
